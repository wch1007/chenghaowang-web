01 / WEB PRODUCT
Web 产品 · UX/UI · 云端媒体2025

Visual Diary Cloud 可视化云端相册

让云存储不只保存文件，而是把照片、视频、笔记与心情重新组织成一座动态记忆画廊。

角色全栈开发 / UX 设计场景UW · TECHIN 510协作Chenghao Wang · Diyun Lu

使用 Next.js、React、TypeScript 与 Tailwind 构建交互式媒体平台。NextAuth 负责安全登录；CSS Grid 组织响应式瀑布流，Intersection Observer 完成懒加载；React Context 管理媒体状态，localStorage 保存笔记与心情标签；归档 / 隐藏功能用 Set 与不可变更新保证界面状态一致。

为什么不只做一个相册？

传统云盘把照片当文件，我希望留下的却是当时的情境和情绪。于是将瀑布流、心情笔记和归档组织成一条“存入—讲述—回看”的路径；保留简单操作，让记忆而不是管理动作成为主角。

实现中的取舍

服务器与客户端组件分工，结合懒加载承接较大媒体；用 Set 与不可变更新区分归档和隐藏状态，归档跨会话保留、隐藏只影响当前浏览。笔记通过状态提升保持多组件一致。

02 / ROBOTICS
机器人感知 · 计算机视觉 · ROS 22025

ROS 2 Robotic Delivery 智能配送机器人

从语音指令到目标识别、抓取、导航与递送的端到端机器人系统；负责让机器真正“看见”并找到物体。

角色感知组 / 视觉算法场景UW GIX · TECHIN 517结果90% E2E · 98.7% mAP@.5

以 YOLOv8、OAK-D RGB-D 相机与 ArUco 建立检测管线，并完成相机坐标到机械臂坐标的转换。六个子团队通过标准 ROS 2 消息与状态机协同；六类目标的 mAP@0.5 达 98.7%，坐标误差控制在 1–2 mm，完整任务成功率达到 90%。

我的工作：把“看见”变成可执行的坐标

在感知子团队中，结合 RGB-D 深度与 YOLOv8 检测，并用 ArUco 标定相机到机械臂的坐标转换。与操作和编排团队统一 ObjectList 消息字段，在 RViz 中共同检查目标位置，减少各模块各自正确、集成却失败的问题。

从单点能力到系统协作

除了识别结果，还需要反馈“目标是否仍存在”。连续丢失目标时，系统进入重试检测与任务状态处理；把检测、坐标、状态和失败情况一起交付，才使感知真正接入完整配送闭环。

X-WBT 户外湿球温度监测器

无需触屏，用手势控制的户外热风险监测器；把环境数据变成即时、可感知的安全提醒。

角色独立设计与开发场景UW GIX · TECHIN 512精度±0.5°C · ±2% RH

基于 QT PY RP2040、APDS-9960 与 BME280，将温湿度、湿球温度与多模态警报装进 3D 打印腕带。通过 10–130 的手势阈值过滤日常摆臂误触；27°C 进入警告、30°C 进入危险状态，并用屏幕、LED 与蜂鸣器同步反馈。

从自己的户外运动问题出发

长跑时很难停下来逐项操作设备，因此选择挥手启停，把温湿度数据变成湿球温度显示，并以灯光和声音提供多通道反馈。弧形外壳、透明屏幕窗口和外露感应区，都围绕运动中的使用方式设计。

解决真实环境中的误触

日常摆臂曾被误判为手势。我分析接近信号后加入阈值过滤，并用线性回归校准温湿度传感器。课程原型把算法、校准、电路、外壳和实际佩戴串在一起，而不只展示一个桌面演示。

GottaGo 共享卫生间智能计时器

用幽默而不是训诫解决共享空间的时间冲突：一只会感知门锁、计时、提醒并“公开处刑”的智能沙漏。

角色产品设计 / 硬件原型场景UW · TECHIN 511A协作4-PERSON TEAM

门锁上的霍尔传感器触发 10 / 20 分钟沙漏，光敏传感器判断计时结束并驱动蜂鸣器；超时则显示趣味 GIF。完成 ESP32 电路、磁铁触发、3D 打印、激光切割与外壳装配，把实体交互、行为设计与数字反馈做成闭环。

看得见的公平，而不是又一条规定

把锁门这个自然动作绑定到计时流程：磁铁与霍尔传感器判断使用状态，光线传感器识别沙漏流尽，解锁后自动停止提醒。用户不需要记住另一套操作，门锁就是交互入口。

让原型经得起下一位使用者

翻转结构可把沙子重新集中到上端，避免上一位没用完的时间影响下一位。通过 3D 打印、亚克力切割和涂装完成装配，再用趣味文案与 GIF 让提醒更温和。

关于我 / CAELEN

Think as a poet.
Act as a scientist.

我是王城昊，Caelen。不是不断换方向，而是在为同一种好奇心，寻找更多解决问题的方式。

01

世界不止一种答案。

北京八中的素质教育让我知道，生活不止学习。在新雅书院，与不同学科、不同思维的人交流，逐渐变成了我的日常：先理解对方眼中的世界，再寻找共同语言。

好奇心 / 共情 / 跨学科沟通
02

既看见人，也看见系统。

建筑学训练了我的审美、调研与需求洞察；数据科学让我习惯从证据出发，用结构和逻辑理解复杂问题。感受力与分析力不是两条路，而是同一件事的两面。

设计审美 / 用户研究 / 数据思维
03

让想法经得起真实世界。

UW 的机器人训练与汤问创业让我学会软硬结合、快速原型；清华计算机人机交互实验室与 UW 的 CS 课程，把 AI、编程和技术思维带进了我的工具箱。

软硬一体 / 快速原型 / HCI / 编程
04

最后，把能力交给用户。

在 HerOS 与阿里巴巴 Accio Work，我继续把这些能力放回真实需求：定义 AI Agent 的任务，设计交互，用评测发现问题，让技术从演示走向日常使用。
